# Infinite Fjords

Procedurally generated Norwegian landscapes.

[View live](https://jonasnico.github.io/infinite-fjords/)

Drag, scroll, or use the arrow keys to explore. Generate a new landscape or save the current view as a PNG.

## Run locally

Requires Node.js 18 or later. No dependencies.

    npm run dev

Open http://localhost:5173.
